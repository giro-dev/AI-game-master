La secció tècnica recorre el backend Spring Boot i el mòdul Foundry TypeScript, els seus contractes REST/WebSocket, els components d’IA i RAG, el model de dades, l’àudio i el desplegament.

## Pàgines

- [Arquitectura](arquitectura/) — context del sistema i pipeline del director.
- [Backend](backend/) — mapa dels paquets i classes.
- [API](api/) — rutes REST, destinations STOMP i missatges.
- [IA, agents i eines](ia-agents-tools/) — clients LLM, prompts, tools i routing.
- [Ingesta RAG](rag-ingesta/) — pipeline, metadades i índex.
- [Model de dades](model-dades/) — entitats JPA i relacions.
- [Àudio](audio/) — STT, TTS i emmagatzematge.
- [Frontend](frontend/) — estructura i procés d’inicialització.
- [Desplegament i desenvolupament](desplegament-desenvolupament/) — serveis, ordres i execució local.
